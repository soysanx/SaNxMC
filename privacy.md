# Política de Privacidad de SaNxMC

**Última actualización:** Octubre de 2026

Esta Política de Privacidad explica cómo nuestro Bot de Discord recopila, utiliza y protege la información de los usuarios y servidores. Al añadir el bot a tu servidor o interactuar con él, aceptas las prácticas descritas en este documento.

### 1. Datos que recopilamos
Para funcionar correctamente, el bot solo accede y almacena los siguientes datos públicos proporcionados por la API de Discord:
* La ID de usuario de Discord.
* La ID del servidor.
* La ID de los canales de texto o voz.
* Datos específicos enviados a través de comandos de barra.

**Nota importante:** Nuestro bot NO lee, NO registra ni almacena el contenido de tus conversaciones privadas, mensajes de texto generales o canales de voz, Solo son usadas como memoria de la IA si usando comandos es activada.

### 2. Cómo usamos la información
Los datos recopilados se utilizan única y exclusivamente para:
* Guardar las configuraciones personalizadas del bot en el servidor.
* Permitir el correcto funcionamiento de los comandos interactivos.
* Mantener registros internos básicos (como sistemas de niveles o economía virtual).

Nunca venderemos, compartiremos ni distribuiremos tu información con terceras personas o empresas.

### 3. Almacenamiento y Eliminación de datos
Los datos se guardan de forma segura. Si el bot es expulsado de un servidor, las configuraciones de ese servidor se eliminarán de nuestros sistemas.

Si eres un usuario y deseas que eliminemos por completo cualquier dato tuyo de nuestra base de datos, puedes solicitarlo enviando un mensaje directo en Discord al desarrollador o unirse al servidor de soporte: **[https://discord.gg/vumUC3YBU4 o @9rbw (Bl4nxz)]**.
